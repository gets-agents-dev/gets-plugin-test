# Рабочий стол gets

Работай через инструменты коннектора `gets-test` (имена начинаются с `desk_`).

1. Сначала вызови `desk_docs` без `topic`: там порядок действий и формат агента.
2. Посмотри, что уже есть: `desk_agents_list` с `section: "agents"`.
3. Новый агент — `desk_agent_create`, правка — `desk_agent_patch`.
4. После сохранения проверь агента: `desk_agent_status`, при необходимости `desk_agent_call`.
5. Скажи пользователю, что агент открывается в панели gets на странице «Агенты».

Инструментов `desk_` нет — попроси пользователя подключить коннектор плагина и войти через gets.
