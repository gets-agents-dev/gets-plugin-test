# gets-plugin-test

Плагин `gets-test` подключает Claude к Рабочему столу gets: агенты, база и файлы стола.

## Установка

- Claude Desktop: Customize → Plugins → Add marketplace → `gets-agents-dev/gets-plugin-test`, затем установить плагин `gets-test` и подключить коннектор на его вкладке Connectors.
- Claude Code: `/plugin marketplace add gets-agents-dev/gets-plugin-test`, затем `/plugin install gets-test@gets-plugin-test`.

Вход — через gets (OAuth) при первом подключении. Ключей и паролей в репозитории нет.

Адрес MCP: https://dev.dard.me/mcp

Файлы создаёт и обновляет основа gets, ручные правки будут перезаписаны.
